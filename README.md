## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/Kshitij-Raj-01/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will start on `http://localhost:3000`.

---

## 📦 Production Build

```bash
npm run build
npm run preview
```

The optimized build will be compiled in `dist/`, ready to deploy on **Vercel**, **Netlify**, **Cloudflare Pages**, or **GitHub Pages**.
